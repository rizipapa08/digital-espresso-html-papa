## Architectural Strategy
This site uses a flat, multi-page structure with four top-level HTML files (index, about, products, branches) connected through a consistent global navigation on every page for predictable crawling (SEO) and easy keyboard/screen-reader navigation (A11y). All shared UI patterns (header/nav/footer) are repeated across pages to keep the document outline consistent and reduce user confusion. Images will live in a single /images folder referenced with relative paths (e.g., images/latte.jpg) to keep assets organized and portable. Each page uses semantic HTML5 landmarks (<header>, <nav>, <main>, <section>, <aside>, <footer>) with a logical heading hierarchy to support accessibility and clean document outlines before CSS styling.
