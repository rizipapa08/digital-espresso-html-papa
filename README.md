## Architectural Strategy
This website is organized into four main pages: Home, About, Products, and Branches. Each page is connected through a navigation menu so visitors can easily move from one page to another. All images are stored inside a single “images” folder to keep everything organized and easy to manage. The website is built using clear and meaningful HTML sections (like header, main content, and footer) so search engines and screen readers can understand the content properly. The goal is to make the structure clean and easy to follow before adding design or styling later.
